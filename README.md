# Oscine website

Marketing site and user guide for [Oscine](https://github.com/thoughtreactordm/oscine), a local music player for Windows and Linux.

```bash
npm install
npm run dev
```

Astro + Vue islands + Nuxt UI (same family as the app). Content for `/learn` lives in `src/content/learn/`. Download links resolve from GitHub Releases at build time.
