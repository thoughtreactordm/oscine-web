Oscine ships a fixed set of shortcuts. They aren't rebindable in this release. The complete list lives under **About → Keyboard shortcuts**; the essentials are here. On a Mac keyboard, read **Ctrl** as **⌘** throughout — the app honors both.

## The command palette

**Ctrl+K** opens the palette over the whole app. Type freely, or lead with a prefix to narrow it to one kind of thing:

| Prefix | Searches |
|---|---|
| `>` | Actions |
| `@` | Artists |
| `#` | Playlists |
| `/` | Settings |

**Ctrl+F** jumps straight into the palette's search, and **Esc** closes it. See [Quick access](/learn/quick-access) for what the palette reaches and the Quick Menu beside it.

## Playback

| Key | Action |
|---|---|
| **Space** | Play / pause |
| **Ctrl+←** / **Ctrl+→** | Previous / next track |
| **Shift+←** / **Shift+→** | Seek back / forward 5 seconds |
| **Ctrl+↑** / **Ctrl+↓** | Volume up / down 5% |

Space stands down while you're typing in a field or when a button is focused, so it never fires playback out from under a click.

## Navigation

| Key | Action |
|---|---|
| **Ctrl+1**–**Ctrl+6** | Jump straight to a tab by its position |
| **Ctrl+K** | Open the command palette |
| **Ctrl+F** | Focus search |
| **Esc** | Close the palette |
| **F11** or **Ctrl+Shift+Z** | Toggle Zen mode |

Zen mode is fullscreen with the chrome hidden; the same key toggles it back, and leaving fullscreen any other way drops out of it too.

## Media keys

Your keyboard's **media keys** — play/pause, next, previous — control Oscine through the operating system, so they work even when the window isn't focused or is behind another app. Oscine appears in the OS now-playing controls the same way: the Windows media card and the Linux (MPRIS) media widget both drive it.

## Double-click

What a double-click does to a song is yours to set — play it now, play it next, add it to the queue, or add it to the open playlist. **Enter** on the focused row does the same thing. A separate setting covers double-clicking an artist or album, so a whole record can behave differently from a single track. Choose both in Interface settings.
